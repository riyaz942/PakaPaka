# README screenshots plan

Screenshots of the app for the root README, as promotional material. Status lives in
[working-history.md](../working-history.md).

## Before you start

- **Put real progress in the app first.** A new install shows an empty ring and empty Stats.
  In onboarding, select **"I know some" → N5** and do the placement check. Then do 1 or 2
  lessons and some reviews. Stop when the goal ring is at approximately 60–80%.
- **Use one phone size for all shots.** A modern iPhone simulator is good. Set the clock to
  9:41 and the battery to full, so the status bar is clean.
- **Take one or two shots in dark mode too.** A light/dark pair side by side looks good.
